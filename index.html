    04 / Quickstart

    Run ibca_core locally.

    The Python package is a pre-alpha foundation: configuration, reproducibility helpers, group-held-out splits, a calibration metric and model/representation interfaces.

    git clone https://github.com/sssihlcodeex/ibca-lab.git
cd ibca-lab/ibca_core
python -m venv .venv && source .venv/bin/activate
pip install -e .
python examples/quickstart.py

    Windows: activate with .venv\Scripts\activate. Add ".[dev]" to install pytest.
