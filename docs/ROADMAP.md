# Roadmap

Planned phases, not completed milestones.

| Phase | Focus | Objectives |
|---|---|---|
| I | Research foundation | Repository, documentation, literature review, problem formulation |
| II | Experimental foundations | Dataset analysis, evaluation protocols, baselines |
| III | Method development | Initial modelling and implementations |
| IV | Validation | Robustness, calibration, independent evaluation |
| V | Open research | Software releases, technical reports, manuscripts |
| VI | Translation | Lightweight tools, self-hosted services, deployment research |

Progress is reflected through releases, issues and documented experiments.
