# Data Governance

- Use datasets only under appropriate permissions and licences; document provenance and restrictions.
- **Never commit** patient records, identifiable medical images, credentials, API keys or confidential datasets to this public repository.
- Follow applicable privacy and data-protection requirements; apply access controls to sensitive data held elsewhere.
- Prefer open, de-identified or simulated data for examples and tests.
- Model weights and datasets may carry licences separate from the MIT code licence.

Report accidental disclosure immediately to saipradyumnat@codeex.space (see `SECURITY.md`).
