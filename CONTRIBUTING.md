# Contributing

Thanks for your interest in IBCA Lab.

## Expectations

- Familiarity with linear algebra, probability and calculus; practical Python experience.
- Roughly 6–8 hours of weekly research activity for core collaborators.
- A commitment to reproducible, open science.

## Workflow

1. Open an issue (bug, feature, or research proposal) before large changes.
2. Fork, branch, and keep pull requests focused.
3. Add type annotations, docstrings and tests for code changes.
4. Run `cd ibca_core && pip install -e ".[dev]" && pytest`.
5. Fill in the pull request template.

## Non-negotiables

- No patient data, identifiable images, secrets or credentials.
- No fabricated results, benchmarks, publications or clinical-validation claims.
- Stay within the three research tracks.

Conduct is governed by `CODE_OF_CONDUCT.md`. Questions: saipradyumnat@codeex.space.
